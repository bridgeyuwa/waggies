# Finishing Touches and Product States

## Enhance what already exists

Before adding new decorative containers, look for opportunities to improve default content already present:

- list markers can become meaningful icons,
- quote marks can become a visual accent,
- selected form controls can use the brand system,
- link treatment can become more deliberate,
- simple content structure can gain hierarchy through typography and spacing.

Do not decorate every element. A few deliberate details create more character than universal ornament.

## Accent borders are punctuation, not structure

Accent borders/lines can add brand energy to a card, alert, active item, section, or page edge. Use them sparingly and consistently.

An accent border must not be the only cue for an important state.

## Decorated backgrounds

When a section is too visually flat, consider, in order:

1. a subtle surface-color change,
2. a restrained gradient using related hues,
3. a low-contrast pattern,
4. a simple geometric shape/illustration.

Decorative backgrounds must remain subordinate to content and preserve contrast, focus visibility, and text readability.

## Empty states are first-class states

Any feature dependent on user-generated data must have an intentional empty state.

A useful empty state should:

- explain what belongs here,
- tell the user what to do next,
- make the next action obvious,
- remove/disable irrelevant filters, tabs, or bulk actions,
- optionally use illustration/iconography to add warmth without obscuring the task.

Do not leave an empty data shell full of controls that cannot yet do anything.

## Separation without box soup

If a page becomes a collection of bordered cards, inspect whether some containers can be removed.

Use spacing, alignment, headings, background changes, and local shadows to create grouping before adding more boxes.

## Reimagine default components when it improves the task

A dropdown can contain grouped sections, descriptions, icons, or multiple columns. A table cell can combine related pieces of content. A radio group can become selectable cards.

Do not change familiar controls purely for novelty. Custom presentation must preserve expected semantics, keyboard behavior, focus, labels, and state communication.

## Design all states

Finishing a component means handling at least the relevant subset of:

- initial/default,
- hover,
- focus-visible,
- pressed,
- selected/current,
- loading/busy,
- disabled,
- empty,
- error,
- success,
- partial/edge-case content,
- long labels and wrapped text.
