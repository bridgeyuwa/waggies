# Waggies local brand marks

These files are local, pinned copies of brand assets sourced from the platforms'
authoritative brand-resource pages. They are rendered locally through the typed
`WaggiesBrandMark` component; runtime UI code does not load remote URLs, CDNs,
icon fonts, or generic icon libraries.

Retrieved 2026-09-08.

| File | Official source | Asset / usage note |
| --- | --- | --- |

| `instagram.svg` | [Instagram Brand Resource Center](https://www.meta.com/brand/resources/instagram/instagram-brand/) | `Instagram_Glyph_Black.svg`; official monochrome glyph used as a local mask for the existing compact control. |

used only as outbound social-link controls and do not imply endorsement.
