# Waggies local Material Symbols

These SVG assets are the local outlined and filled projection used by the
Waggies icon registry. They are sourced from `@material-symbols/svg-400`
(`0.47.1`), whose package and source are maintained at
https://github.com/marella/material-symbols.

Material Symbols are available under the Apache License 2.0. See the package
license in `node_modules/@material-symbols/svg-400/LICENSE` and the registry at
`src/components/waggies/waggies-icon.tsx` for the verified semantic mapping.
